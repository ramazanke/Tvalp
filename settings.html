Kanal listesi kaynağı

Doğrudan M3U / JSON dosyası veya bu listeyi döndüren PHP adresi gir. GitHub dosya bağlantıları da kullanılabilir.

Sunucu CORS izni vermiyorsa listeyi yeni sekmede açıp indir; ardından buradan dosyayı seç. Dosyadan alınan liste otomatik olarak uzaktan güncellenmez.

Bu ayar yalnızca bu tarayıcıda geçerlidir. GitHub dosyalarını veya başka cihazların ayarlarını değiştirmez. Yerel olarak eklediğin kanallar silinmez.

Liste ile yayın adresi farklıdır

Buraya kanal listesinin adresini gir. Tek bir kanalın M3U8 yayınını Kanal yönetimi sayfasından ekleyebilirsin.

Sunucunun tarayıcı erişimine (CORS) izin vermesi gerekir. HTTPS sayfada HTTP’ye yönlendirilen listeler veya yayınlar engellenebilir. Kaynak adresini değiştirmek bu engelleri kaldırmaz.
